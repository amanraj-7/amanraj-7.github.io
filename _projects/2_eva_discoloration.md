**Dissertation Chapter 2** · Arizona State University · Advisor: [Dr. Dwarakanath Ravikumar](https://search.asu.edu/profile/1869256)

#### The problem

Yellowing and browning of the ethylene-vinyl acetate (EVA) encapsulant reduce light transmission and power output, so a crack-free but discolored module may not be suitable for direct reuse. Discoloration is currently graded by subjective manual visual inspection.

#### What we are doing

Building on the crack-detection framework from [Chapter 1](../1_hsi_cracks/), this project aims to:

- Identify the spectral features that distinguish discolored from intact EVA
- Adapt the hyperspectral imaging and machine learning pipeline to classify discoloration severity
- Integrate discoloration and crack status into a condition-based routing scheme that assigns each module to reuse, refurbishment, or recycling

#### Why it matters

Discoloration severity refines the on-site routing decision made with crack information alone. For example, a crack-free module with severe discoloration generates less power, which reduces its resale value and may shift it from reuse to recycling. We measure the value of this information as an increment over the value of crack information.
